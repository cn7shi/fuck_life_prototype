# FUCK-LIFE // 原型探索 (Prototype Exploration)

> 一款个人生活记录与目标管理软件的前期视觉与交互原型探索。

---

## 🎨 三种设计风格

本项目在同一套数据内核下，探索了三种不同的视觉与交互风格：

- 🌑 **SYS_REBEL (赛博粗野朋克)**
- ⚪ **PRTS_WHITE (战术协议白)**
- ⚜️ **HEAVEN_GRIEF (先锋哥特黑金)**
